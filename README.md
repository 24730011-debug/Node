# NODE

학원 강사와 조교가 학생별 학습 기록과 출결을 한곳에서 관리하는 웹서비스입니다.

## PRD (제품 요구사항 문서)

### 사용자와 문제

학원 강사와 조교는 수업 전에 학생별 진도와 숙제를 확인하고, 수업 후에는 새로 진행한 진도와 숙제, 출결, 보강 내용을 기록합니다. 정보가 여러 문서와 메모에 흩어져 있어 학생 한 명의 상태를 확인하고 갱신하는 데 시간이 걸립니다.

### 목표 및 요구사항

| 요구사항 | 확인 기준 |
| --- | --- |
| 학생 찾기 | 학생 목록에서 이름·학교·반 등으로 검색하거나 학년·과목 조건으로 좁힐 수 있습니다. |
| 학생 상세 조회 | 학생을 선택해 기본 정보와 진도·숙제·메모 등 학습 기록을 확인할 수 있습니다. |
| 학습 기록 저장 | 숙제 상태나 메모를 수정한 뒤 같은 브라우저에서 새로고침해도 변경이 유지됩니다. |
| 출결 확인 | 날짜와 반을 선택해 반별 총원, 출석(지각 포함), 결석, 미기록을 구분해 볼 수 있습니다. |
| 수업 후속 관리 | 대시보드에서 미완료 숙제와 예정 보강을 확인할 수 있습니다. |

PC 웹 화면을 우선으로 제작했습니다. 시연에는 합성 학생 데이터를 사용하며 작성한 기록은 같은 브라우저의 LocalStorage에 저장됩니다.

### 2026-11-22 · 날짜별 샘플 자동 생성

- 지난달부터 오늘까지 날짜·학생 기준으로 고정된 샘플 출결, 숙제, 테스트 결과, 보강을 생성합니다. 대시보드에서 다른 날짜를 선택해도 생성됩니다.
- 직접 수정하거나 삭제한 기록을 우선하며, 자동 생성 원본은 저장 시 제외하고 다시 구성해 저장 용량을 줄였습니다.

- 잠실중학교 중1·중2·중3에 김민준 동명이인 샘플을 배치했습니다.
- 통합 검색과 학생 검색에서 학교명 일부를 입력한 뒤 학년별로 학생을 확인할 수 있습니다.

### 2026-11-22 · 숙제 확인 집계

- 반별 오늘 숙제 확인은 선택일 출석 학생 중 확인 날짜가 기록된 학생 수로 표시합니다. 여러 숙제를 확인해도 학생은 한 명으로 계산하며 미완료 확인도 포함합니다.
- 누적 미완료 숙제는 입력창 아래에서 학생 수·건수와 경과 일수, 완료 버튼으로 확인합니다.
- 수정하지 않은 샘플 숙제는 대부분 2일 후 완료된 상태로 정리합니다.

### 2026-11-22 · 뒤로가기와 앞으로가기

- 이전 페이지 버튼이 브라우저 방문 기록을 사용하도록 변경했습니다.
- 브라우저 뒤로가기·앞으로가기 시 해당 화면과 스크롤을 복원합니다.

- 공통 상단에 뒤로가기·앞으로가기 버튼을 추가했습니다. 전체 숙제는 페이지별로 표시해 많은 기록이 있어도 이동할 수 있습니다.
